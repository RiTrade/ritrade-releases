# RiTrade 1.2.13

_Released 2026-06-25_

### Added

- **The User Guide now shows you how to manage your dashboard tabs.** A new
  section in "The dashboard at a glance" covers adding a dashboard (the + at the
  end of the tab strip, with the option to start from a copy of another
  dashboard's layout), renaming or adjusting one, and removing one - all from the
  right-click menu on a tab. The guide previously mentioned the + only in passing
  and never explained that rename and delete live on a tab's right-click menu.
- **The guide also explains what each dashboard setting does.** A companion "What
  each dashboard setting does" section walks the Edit Dashboard form field by
  field - the name on the tab, the timezone the dashboard reads your trades in
  (and how it decides which day a trade falls on), the time period it covers, and
  the choice of whether it keeps its own filters or follows the shared Global
  filter - with an annotated screenshot of the form.
