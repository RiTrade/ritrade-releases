# RiTrade 1.2.2

_Released 2026-06-13_

### Changed

- **New RiTrade logo and app icon.** The header now shows the RiTrade mark
  beside the name, the sign-in screen carries the full stacked logo, and the
  window / taskbar / browser-tab icon uses the new brand icon. The header
  wordmark follows the active theme, so the name stays crisp on dark and light
  themes alike.
- **New default theme "Ember".** Fresh installs now open on a brand theme — a
  cool dark base with the RiTrade orange as the accent (buttons, links, active
  states) and green/red P&L. Midnight (the former default) remains available in
  Settings - Theme, alongside every other theme. New installs also default to
  the Classic green/red P&L colours rather than Tonal.
- **Sign-in screen restyled to the brand.** The "Sign in" button, links and
  focus states are now RiTrade orange instead of blue.
- **Installer file renamed to `RiTrade-setup-<version>.exe`** (was
  `setup-<version>.exe`), so the download on the releases page carries the
  product name. Existing installs auto-update normally - the updater follows the
  manifest's download URL, so the rename is backward-compatible.
