# RiTrade Releases

Public download channel for [RiTrade](https://github.com/RiTrade/ritrade-code) — a local trading journal that ingests broker reports (XLS, PDF, REST) and renders customizable dashboards.

## Latest

**[v1.0.0](https://github.com/RiTrade/ritrade-releases/releases/tag/v1.0.0)** — first public release.

- Download: [setup-1.0.0.exe](https://github.com/RiTrade/ritrade-releases/releases/download/v1.0.0/setup-1.0.0.exe) (42.8 MB)
- SHA256: [setup-1.0.0.exe.sha256](https://github.com/RiTrade/ritrade-releases/releases/download/v1.0.0/setup-1.0.0.exe.sha256)

After installing, RiTrade runs locally on `http://localhost:5000`. No accounts, no cloud, no telemetry.

## Verify the download

        Get-FileHash setup-1.0.0.exe -Algorithm SHA256

Compare with the value in `setup-1.0.0.exe.sha256`. If they don't match, do not install — re-download from the link above.
