# RiTrade 1.2.23

### Improvements

- Dashboard KPI numbers now grow with the tile, so a stat you enlarge for a wall-mounted or read-from-across-the-room dashboard fills its space instead of capping at a fixed size and floating in empty space.

- The RiTrade download is leaner and cleaner - it now carries only the app itself, with none of the stray working files that could slip in alongside it, so what you install is just the product and nothing extra riding along.
