# RiTrade 1.2.9

_Released 2026-06-23_

### Fixed

- **Setting up a "watch a folder" account now starts you in the right place.** The
  first time you sync a folder account, RiTrade asks you to pick one file so it can
  learn the layout - and that file picker now opens **inside the folder you chose to
  watch**, instead of starting you off in Documents. One click, instead of hunting
  across your drive for the folder you already pointed us at. And once you've mapped
  that first file, RiTrade brings in the rest of the folder right then - no need to
  press Sync again - and tells you it'll keep pulling in anything you add later. The
  ordinary "Import a file" button for one-off imports is unchanged. (Work 0181.)
